# CodeAlpha Data Analytics Internship

Welcome to my Data Analytics Internship repository! This repository contains all the tasks and projects I completed during my data-driven journey as an intern at **CodeAlpha**.

## 📌 Internship Overview
The objective of this internship was to gain hands-on experience in data analysis, visualization, and interpretation. Throughout this program, I utilized Python and its powerful libraries to extract insights, clean data, and build impactful data stories.

## 📁 Repository Structure & Completed Tasks

This repository is organized into separate folders for each task. You can click on any task folder below to view the detailed code, datasets, and generated visualizations.

| Task Directory | Project Title | Description |
| :--- | :--- | :--- |
| 📂 **[Task_1](./Task_1)** | **Exploratory Data Analysis (EDA)** | An in-depth EDA on the classic Titanic dataset to uncover survival patterns, handle missing data, and analyze demographics. |
| 📂 **[Task_2](./Task_2)** | **Data Visualization** | A comprehensive visual dashboard of the Titanic dataset using Matplotlib and Seaborn to tell compelling data stories. |
| 📂 **[Task_3](./Task_3)** | **Sentiment Analysis** | Natural Language Processing (NLP) on Amazon customer reviews using TextBlob and VADER to classify feedback as Positive, Negative, or Neutral. |

## 🛠️ Tech Stack & Libraries Used
* **Programming Language:** Python
* **Data Manipulation & Analysis:** pandas, numpy
* **Data Visualization:** matplotlib, seaborn, wordcloud
* **Natural Language Processing (NLP):** nltk, textblob, VADER
* **Development Environment:** Jupyter Notebook

## 🚀 How to Explore the Projects
1. Clone this repository to your local machine:
   git clone https://github.com/AnujKumarTiwari/CodeAlpha_ProjectName.git
2. Navigate to the specific task folder you want to explore:
   cd CodeAlpha_ProjectName/Task_1
3. Open the `.ipynb` (Jupyter Notebook) files to see the step-by-step analysis, code execution, and insights.
